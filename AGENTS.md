# ZenImport — последовательный рефакторинг

Общение по-русски. Актуальный план: docs/refactor/README.md; состояние:
docs/refactor/05-progress.md; HTTP-контракт: docs/sync-api-v1.md.
Старые документы описывают прежний UI и не отменяют новый план.
Работать по этапам, проверять в изолированном Docker, обновлять журнал.
По завершённым этапам делать локальные Git-коммиты. Push, теги и публикация
требуют отдельного явного разрешения пользователя.
Не изменять рабочую БД и не вызывать настоящий ZenMoney в автотестах.
SDK остаётся независимым; коннекторы банков — модули Chrome extension.
Не возвращать редакторы/сверку и UI-инъекции в банковские страницы.
Документацию сторонних библиотек при изменении их использования проверять
через Context7; не выдавать синтетические тесты за проверку живого банка.
