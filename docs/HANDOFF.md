## Ограничения и правила

Один пользователь/worker, SQLite WAL, сеть пока внутри транзакции. Ответ ограничен 64 МиБ; архив растёт без retention. Budget deletion по составному ключу пока явно отклоняется до реального fixture. Неизвестные поля/коллекции архивируются, но не все имеют отдельные колонки. Прототип `zen_entities` пока нужен demo-matching/outbox.

Общаться по-русски. Локальные проверки — Docker. Токены/БД/debug не коммитить, не выводить в чат, не включать в образ. Не удалять обычные тома ради теста. `.venv` только вспомогательная. Документация библиотек — Context7, затем официальные источники. Не перепрыгивать к live-записи и не объявлять fixture-тесты приёмкой реального банка/API.
