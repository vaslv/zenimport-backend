# Самостоятельный проект ZenMoneyAPI

13 октября 2026 библиотека перенесена из `packages/zenmoney-client` в соседний
проект `/Users/vaslv/Projects/Vaslv/ZenMoneyAPI`, со своей историей Git, сборкой,
документацией и тестами. Backend и Chrome остаются здесь, в ZenImport.

ZenImport устанавливает фиксированный wheel 0.4.0 из `vendor/`; SHA256 проверяется
при сборке Docker. Исходники SDK не дублируются и не подключаются через symlink.
Обычная сборка приложения не зависит от наличия соседней папки.

Старый namespace `zenimport_zenmoney` сохранён как совместимый адаптер. Новые
возможности общего API доступны через `zenmoney_api`, но не включаются в UI
автоматически. Прежние проверки категорий/создания, лимит пакета и журнал
отправок приложения сохранены.

- SDK: HTTP/OAuth, протокол diff/suggest, модели, сериализация, ошибки.
- Backend: БД, курсоры, привязка счетов, категории, сопоставление и подтверждение.
- Банковские адаптеры: извлечение/нормализация данных банка.
- Расширение/SPA: интерфейс и действия пользователя.

Разработка API продолжается в [ZenMoneyAPI](../../ZenMoneyAPI/README.md).
Покрытие и ограничения: [матрица](../../ZenMoneyAPI/docs/coverage.md).
Обновление зависимости: [vendor](../vendor/README.md).

Разделение backend, Chrome и банковских коннекторов на дополнительные проекты
отложено. При этом переносе настоящие записи ZenMoney не изменялись.

Совместимость wheel 0.4.0 проверена полным Docker-прогоном: 159 backend-тестов,
19 тестов парсеров, 70 браузерных сценариев, HTTP smoke и проверка сохранности
данных при пересоздании тестового контейнера — успешно.
