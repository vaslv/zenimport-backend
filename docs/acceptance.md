## Ограничения

- Установленное расширение в Chrome ещё не прошло UI-приёмку: это этап 2.
- Готовая библиотека или отдельный пакет ZenMoney пока не выбраны. Текущий HTTP-клиент предварительный.
- JSON-зеркало не является окончательной структурой БД всех сущностей API.
- Живой ZenMoney, настоящие банки, историческая полнота, подсказки и live-запись не проверялись.
- Проверена ARM64-сборка. AMD64-сборку и серверное развёртывание следует проверить в выбранном окружении; multi-architecture базовые образы сами по себе не доказывают такую приёмку.
- В тестах остаётся upstream deprecation warning TestClient/httpx; ошибок тестов нет.
- Для сборки из ограниченной среды Codex использовался отдельный writable каталог BUILDX_CONFIG в рабочей области, поскольку стандартный каталог Docker Buildx был недоступен для записи. В обычном пользовательском терминале дополнительная настройка не требуется.

Git push, создание тегов, публикация образов и развёртывание на удалённый сервер не выполнялись.

## Интерфейс ZenMoney — счета и операции, 6 октября 2026

Выполнены замечания пользователя: отдельные вкладки Счета/Операции/Категории, архивные счета скрыты по умолчанию с переключателем, нажатие карточки открывает account-фильтр. Денежные десятичные строки форматируются без округления через Number; привычные минимальные разряды валют сохранены.

Полный Docker-прогон: **56 Python + 3 parser + 14 browser = 73 теста — PASS**, дополнительно HTTP smoke и сохранность данных при пересоздании. Новый браузерный сценарий проверяет вкладки/клавиатуру, архив, drill-down, сброс фильтра, обе стороны валютного перевода, группировку, категории и точные большие/дробные суммы. API account-фильтра ранее проверен серверными тестами; новый UI-тест использует синтетические данные и проверяет отправленный параметр account.

Просмотрены screenshots широкого экрана 1440px и узкого 390px: горизонтальной прокрутки нет, архивный счёт скрыт, суммы читаемы. Скриншоты в test-results/ содержат только искусственные данные. Изменение UI не выполняет записей в ZenMoney. После обновления файлов пользователь должен перезагрузить расширение и его открытую SPA.
