Если загрузка не работает

Откройте DevTools → Network в банковской вкладке и повторите поиск с изменённым периодом. Можно также загрузить сохранённый ответ банка.

Старый способ: чтение таблицы

Резервный способ без подробностей JSON. Для всех страниц: страница 1, Filter открыт, Search применён. Держите окно расширения открытым.
